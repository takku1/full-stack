# FS-015 first end-to-end trial of 0.5.0, 2026-11-12

One headless session, no repeats. Claude Code 2.1.322, Windows 11, `sonnet` (Claude Sonnet 5.5). The plugin was loaded with `--plugin-dir ./skill`, using an isolated `CLAUDE_CONFIG_DIR` and `--strict-mcp-config` with an empty MCP config. Harness: [`evals/fs015_trial.py`](../fs015_trial.py). Task: design and build a small multi-user to-do HTTP API (standard library only; private lists; 401 without a token; another user gets 404; data survives a restart). Retained: [`summary.json`](fs015-2026-11-12/summary.json) and the [workspace](fs015-2026-11-12/workspace/) (app, tests, the model's notes). The raw transcript stays local (gitignored).

## Reading

On a small task the outcome was correct and the security-relevant behavior was good. The model followed the package's *intent* (read the modules, test the risky paths, report honestly) while skipping its *ceremony* (stack records, assurance table, guard). The cost and turns stayed close to the brief's FS-009 range. This is consistent with the FS-009 reading that the structured process may pay off only on larger, coupled, or multi-worker work. One session cannot say whether the skipped steps would have changed the outcome; FS-016 with planted defects is the test.

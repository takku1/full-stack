# Full Stack roadmap

This file tracks incomplete project work. Package 0.4.0 ([D-017](docs/design-decisions.md#d-017-modular-layer-orchestration-package-040)) restructures the skill into a small core, on-demand flows, and layer modules; FS-011..FS-018 track it. Package 0.5.0 adds the assurance dimension (D-020, owner exception to the freeze). **Feature freeze from 2026-11-12:** no new features until FS-023 (live plugin), FS-015 (first trial), and FS-016 (comparative evaluation) report, in that order. Fixes to observed defects are still allowed. Package 0.3.0 ([D-015](docs/design-decisions.md#d-015-fresh-user-review-and-second-field-report-package-030)) applies the [fresh-user review](docs/research/review-2026-10-05-fresh-user.md); retained [trial evidence](evals/results/revision-review.md) predates it. No sample establishes comparative effectiveness.

| FS-016 | Comparative evaluation (main evidence gate) | Research | **Arms (all parts):** plain Claude Code, the 312-token brief, 0.3.0, 0.4.0, and 0.5.0, at matched budgets with blind grading and at least three sessions per cell. **Prerequisite:** session isolation that keeps account connectors out of test sessions (seen in FS-023), so cost comparisons are not inflated. **Cases:** (1) stack selection: four or more greenfield briefs, two existing-repo cases, and one adversarial case whose declared tags look compatible but whose real operational limits make it a poor choice; (2) assurance: a flawed multi-tenant app with a planted object-level authorization hole and an unsafe retry path, plus planted failures for a failed migration and secrets or personal data in logs; (3) screen recall: a local tool that runs untrusted plugins or reads confidential files. **Measures:** architectural coherence, missed requirements, task completion, justification, regret awareness, unneeded technology or infrastructure, scope honesty, planted-defect detection and fix, check meaningfulness (the agent's check fails when the planted defect is present; a passing check on the wrong path counts as a miss), screen recall and unneeded rigor, tokens, turns, and cost per accepted task. **Decision rules:** if the brief wins on ordinary tasks, narrow Full Stack's description to coupled, high-consequence work; keep the assurance dimension (FS-026) only if 0.5.0 catches more planted failures than 0.4.0 without failing non-inferiority where the screen should stay quiet |
